日期：2026-09-27（北京时间）。执行者：Codex。用户方向：AI 光模块与网络互连；视觉靠近同花顺；源码公开、网站公开；保留模型接口，未接 API 可演示；视频暂不制作。

## AI 使用范围

1. 需求拆解：从产业链归属、概念真实性、可比公司、传导路径提炼六个工作台视图。
2. 材料研究：搜索官方公告和公司投资者关系网站。提取公司、产品、时点、业务口径与原文定位。未使用非公开信息或付费终端。
3. 实现：生成 React 界面、云端记录和模型适配器，编写情景计算与规则检索。
4. 验证：类型检查、生产构建、核心断言、真实本地 API 与浏览器交互检查；模型和外部来源故障通过注入测试。

- “中际旭创有多少 AI 收入？”：给出模块相关收入，同时明确 AI 专属收入未单列。

- “CPO 会替代可插拔光模块吗？”：不作必然替代结论，说明技术、良率与客户验证限制。

- 未覆盖主题：明确证据不足，不补造来源。
