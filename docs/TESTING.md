## 复跑

先按 README 启动服务并初始化本地数据库，再执行：

```sh
node node_modules/typescript/bin/tsc --noEmit --incremental false
node tests/core.mjs
node tests/faults.mjs
node tests/api.mjs
npm run build
```

HTTP 测试默认 localhost:5174，其他地址请配置 TEST_BASE_URL。故障测试依赖 core 测试生成的临时转译模块；测试产物只写入忽略的 work 目录及 docs 下结果 JSON。每次 HTTP 测试使用独立匿名会话，不操作他人的研究工作区。
