# 光链研究 OpticChain

AI 光模块与网络互连研究工作台。采用贴近中文金融终端的红白配色、紧凑表格与分栏详情，自有品牌，不使用同花顺标识或资产。

## 目标用户

产业研究员、投研助理和希望核验热门概念的进阶投资者。核心问题是：公司在产业链哪一环？业务证据到哪一步？海外同业是否真正可比？变化通过什么假设影响财务？

## 可运行主链路

1. 产业图谱：芯片与光源、器件与封装、光模块、交换系统、算力需求，共五层、十家去重公司。支持跨环节归属。箭头是功能关联，不证明具体供货。
2. 公司证据：搜索和筛选，五级关系状态，收入的币种、期间、分部范围与原文定位。没有数据保留缺失，不填零。
3. 跨市场比较：三组中外比较，明确产品交集、非重合业务、财年、币种和会计准则。禁止未调整的集团估值映射。
4. 事件传导：历史资本开支指引、CPO 技术变化、物料成本假设；分别显示事实、条件推断和验证信号。
5. 敏感性模型：六个可交互参数，输出归一收入和毛利率、公开公式、输入与结果导出。不是公司盈利预测。
6. 持续更新：检查官方链接、计算 SHA-256、保存前后指纹；录入新官方来源和证据；人工采纳/不采纳；保存审计轨迹。补充证据显示在公司档案，并参与该工作区演示问答。
7. AI 研究助手：不接模型即可检索已核对证据；真实模型适配接口已保留。

## 数据使用与时间

- 基准快照截至 **2025-08-31**，主要是 2024 自然年与 FY2025 官方资料。资料核对日期为 **2026-09-27**。这是有明确时点的历史研究库，不是实时行情。
- 10 份基准来源全部在 `lib/research-data.ts`，包含公司公告/巨潮资讯、Coherent、Lumentum、Arista、Broadcom、Marvell、NVIDIA、Alphabet 的官方资料；网页与报告原件保留在原站，只保存短摘要和定位。
- “载入 2026 公告样例”使用 NVIDIA 2026-05-31 官方公开进展，帮助演示从历史规划到后续产品阶段的证据更新，保存时明确用户复核，不自动改写旧数据。
- 不接入扶摇、iFinD，不冒充其数据；不提供股价、市值或实时估值。
- 中际旭创模块收入 22,885,756,727.93 元、新易盛点对点模块收入 8,591,708,917.12 元均由年报取得；亿元转换可复算。Lumentum 分部占比由 1,410.8 / 1,645.0 计算。业务收入不等于 AI 专属收入。
- 来源内容指纹变化可能是页面模板变化，并不证明业务变化。来源故障时保留旧证据、标记错误，不自动降级公司的业务关系。

## AI 的角色

开发阶段：AI 协助方案、结构化材料、代码和测试。关键数字通过官方材料及计算断言核对，记录见 `docs/AI_USAGE_AND_VALIDATION.md`。

产品演示：确定性规则检索 + 已核对解读模板，无需调用付费模型；明确标注“规则检索 · 演示”。可以处理覆盖公司、可比、资本开支及 CPO 问题，未知问题承认证据不足。用户已采纳补充证据只在当前工作区按公司匹配追加，不伪装为原始审计披露。

在线模型：`POST /api/research` 支持兼容 Chat Completions 的 HTTPS 服务端调用。需要 `MODEL_BASE_URL`（以 `/v1` 等基础路径结尾）、`MODEL_NAME`、`MODEL_API_KEY`、`MODEL_ACCESS_TOKEN`。使用 Sites 环境变量配置；密钥只在服务端。网页只接收访问口令，存在当前页面内存中。未配置则明确回退，网络/鉴权/格式失败明确报错。回答结构和来源 ID 校验通过后仍标为待人工核验。在线模型目前仅使用基准公开证据库，不接收新增工作区材料。

## 运行

要求 Node.js 22.13+，npm。Cloudflare Workers 兼容运行时由 Vinext/Vite/Wrangler 提供。

```sh
npm ci
npm run build
node --import ./scripts/sites-env.mjs ./node_modules/wrangler/bin/wrangler.js d1 execute DB --local --config dist/server/wrangler.json --persist-to .wrangler/state --file drizzle/0000_absent_glorian.sql
npm run dev
```

只在首次本地初始化执行上述迁移，不重复执行已经应用的迁移。访问终端打印的 localhost 地址（通常 5173，被占用会顺延）。平台发布时使用 Sites 的 D1 绑定和迁移机制。

独立克隆环境首次运行若缺少 `.sites-runtime/execution-profile.json`，项目按 portable 默认运行。无需安装全局框架。

## 架构与存储

React + TypeScript + Vinext，Cloudflare Worker API，D1 SQLite 持久化。`db/schema.ts` 定义记录与限频表，`drizzle/` 保存迁移。公开访问无需账号；使用服务端随机 UUID 和 HttpOnly、SameSite Cookie 隔离匿名工作区，生产 HTTPS 使用 Secure。浏览器不存储权威记录。只向已批准官方域名发起来源抓取，禁止重定向、非 HTTPS、私网和任意地址；单源上限 12MB，超时 12 秒。

用户记录不是跨设备账号系统。Cookie 有效期 30 天；清除 Cookie 会失去工作区入口。可导出记录留存；当前不提供导入恢复、多人协作和账号迁移。读取最近 500 条记录，更新历史展示最近 20 条；不是无限量研究数据库。匿名工作区只存公开研究材料，不适合存储私密资料。

## 已知边界与未做事项

- 尚未付费调用真实模型，在线适配器用故障注入测试验证，真实供应商兼容性需配置后验证。
- 没有全网自动发现公告、PDF OCR、全文向量检索、定时无人值守采集和自动财务归一化。当前支持手动检查、录入新材料、人工审核；源码证据库也可版本化更新。
- 证据级别针对具体关系和材料时点；Marvell/NVIDIA 的低阶段标签不能理解为其整家公司当前业务成熟度。
- 基准图谱保持历史版本；补充证据保留独立时点，不自动覆盖其他研究对象或旧财务指标。
- 新增来源域名限制为已纳入台账的官方域名；扩展白名单需修改代码并重新发布。
- 简化敏感性计算忽略固定成本、汇率、税、良率和库存滞后；不输出目标价、保证收益或个性化买卖指令。
- 没有进行第三方渗透测试；模型引用 ID 正确不保证逐句事实正确，仍需人工阅读原文。
- 演示视频由使用者实际操作后录屏，本次按要求暂不制作。
